## Formula additions for scientific reproduction

1. **Data and baseline.** Define township households $H_t=\sum_{i\in t}H_i$, subscriptions $S_t=\sum_{i\in t}S_i$, the reported coverage proxy $A_t=\sum_{i\in t} H_iM_i/H_t$, and $b_t(\alpha)=\sum_{i\in t}1[M_i=1,\ T_i\in\{\mathrm{fiber,cable,FWA}\}]\lfloor\alpha H_i\rfloor$. The nominal $\alpha$ is 1 and the stress is .75. Floor the stress per block before summation as the code does. The proxy is conditioned on claim fields. The inputs cannot rule out undocumented service in other blocks. Put the optional Task 1 length-weighted weak-signal diagnostic beside its result, $\sum_s L_s1[\mathrm{dBm}_s\le-110]/\sum_s L_s$, for segments joined only to the specified technology group. The reclassification ladder is $R(q)=\lfloor1531q+0.5\rfloor$. Its $q$ values are scenario fractions. They are unrelated to the capacity proxy or challenge-success probabilities.
2. **Rule, coverage and floors.** Let $v_i$ be a hypothetical accepted verification flag for the 13 North Ridge satellite-coded blocks. The original rule uses $E_i=1-\max_{k\in t(i)} M_k$, block reform uses $E_i=1-M_i$, and the block reform plus override uses $E_i=\max(1-M_i,v_i)$. If the county only corrects the map while retaining the veto, use $1-\max_{k\in t(i)} M_k(1-v_k)$, which remains zero in each township. Define $G_t=\sum_{a:i(a)\in t}h_ax_a$, $L_t=\lceil\tau H_t\rceil$, $D_t=\max(0,L_t-b_t-G_t)$ and post-access share $(b_t+G_t)/H_t$. Only the equity inequality is dropped for the no-equity comparison. Code sets its right-hand requirement to zero, so the surviving inequality is redundant.
3. **Discrete capacity and two objectives.** State $h_{iW}=\lfloor p_{g_i}H_i\rfloor$ with exact hundredths or numerator arithmetic. Block 420010000115 has $H_i=170$ and reach 70%, giving 119. In a binary floating implementation, using floor on the machine approximation of $170\times0.70$ can incorrectly give 118. State the second optimization explicitly as $\min C$ subject to $G=G^\star$, where $G^\star=\max G$ under the common constraints. State the separate budget threshold $B_{\min}=\min C$ under eligibility and floors, dropping the coverage objective. The code also caps that run at the common budget. Its feasible minima under that cap are the unrestricted cost minima.
4. **Mechanism action costs and cash flows.** For a hub with medians $d_j,g_j$ from originally unserved blocks, $K^H_j=\operatorname{round}(25000+42240d_j[1+0.16(g_j-1)])$, and hub PV is $K^H_j+\operatorname{round}(A\cdot0.018K^H_j)$. For a hub-dependent action in block $i$, $\ell_{ij}=|d_i-d_j|+0.5$ and the lateral backhaul is the rounded base direct backhaul coefficient multiplied by $\ell_{ij}/d_i$ and then rounded again. Technology, service condition and the supplier's last-mile multiplier remain explicit. For equal-coverage offers in one block/technology/hub grouping, minimizing the bid cost is equivalent to minimizing its unit cost $c_a/h_a$. The portfolio remains a lexicographic coverage-and-cost optimization. Define $N$ as the count of distinct selected provider–hub pairs, $R_{\mathrm{lease}}=N\operatorname{round}(4800A)$, $C_{\mathrm{county,net}}=C_{\mathrm{gross}}-R_{\mathrm{lease}}$, operating recovery $R_{\mathrm{lease}}/\mathrm{PVOM}_{\mathrm{hub}}$ and the approximate annual break-even per lease $\mathrm{PVOM}_{\mathrm{hub}}/(AN)$. State that commissioning at least one hub applies to the authorized PPP deployment scenario. In the strict case there is no eligible hub procurement and the commissioning condition is inactive.
5. **Interpretation.** The reported 25% threshold is a modeled first-phase standard. Its North Ridge block-only ceiling is 28.29%, which motivates treating the 50% case separately. New opportunities are model passings. Neither the existing claim proxy nor the new passings establish adoption or adequate work and school service. Site verification, correspondence of bidders and map claims, full funding, private lease commitments and the reach caps remain assumptions to validate.
